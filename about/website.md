# 关于网站

网站由 [Serialist](https://www.serialist.top) 搭建并作为管理员，基于 wiki.js 应用构建。

## Q&A

### 为什么要有这个网站

我想我们需要一种能够共同协作、便于查看、记录文档的方式，来管理我们队伍的文档。

钉钉、网盘等等方式较为难以查看，也不便于向新队员和外界展示我们，所以我选择了搭建 wiki。

当然，一些和飞书文档结合的模式也很有意思，所以后续我们会不断尝试，让 VGD 的文档管理更好

### 什么是 wiki

wiki 是一种协作方式（其实就是指大家一起编辑文档/类似在线文档）。

### 怎么保存，怎么看网站的文件

网站的所有文件都保存在 [我们的 Github 仓库](https://github.com/chuvgd/chuvgd-wiki) 中，每 5min 同步一次，所以你也可以通过 git 来进行文档编写（请提 pr 而不是直接 commit 在 main 分支中！！！）

图像文件同样会储存在git仓库中（但为了减少git仓库占用，以后会考虑使用图床来进行管理）

### 如何注册

按照流程注册就行，注册时会以 `wiki@chuvgd.cn` 的邮箱向你发送验证邮件。

如果有问题（例如注册失败）请联系管理员（或向wiki@chuvgd.cn发邮件，如果我看见会处理的，如果你能直接联系上当然更好）

### 怎么编写文字 or 编辑文章

*我们推荐使用markdown格式编写文章！*

点击右上角图标分别可以编辑/添加文章。
