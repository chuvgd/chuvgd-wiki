# 关于算法组

![ag1.webp](/about/assets/ag1.webp)

算法组是机器人的大脑和灵魂，偏向于上层软件程序的开发，提供战场的全知视野，自瞄辅助和自主决策，让机器人能够更好地应对场上复杂地形和瞬息万变的战局，同时对敌方机器人进行易伤和压制，更好地辅助我方机器人进行进攻和胜利。

## 主要职能

算法组主要的核心工作是模块化开发各种特定的功能——主要分为自瞄辅助射击，自主决策导航，全知视野分析大局。

### 自瞄辅助射击

在赛场上，我们需要进行对装甲板进行打击，而敌方机器人很大可能会开启小陀螺进行防御，这时候就需要我们的自瞄系统对小陀螺进行反制，俗称“反小陀螺”算法，主要是对装甲板的灯条和图案进行识别，对整车装甲板进行建模，对弹丸进行弹道分析和解算，最后实行开火指令进行打击。

### 自主决策导航

哨兵机器人作为场上唯一全自动机器人，需要算法对其进行整个自主系统进行设计，一般分为定位与感知，路径规划和运动控制，自主决策设计，在设计算法的过程中，我们要结合机械相关特征和电控调试，不断迭代相关算法做到满足战术上对敌方机器人的打击。

### 全知视野

“信息收集与收集中枢，拥有最佳算力，为全队提供战略与战术信息，并能够反制空中机器人”。

雷达，如同她的名字一样，能够做到探测敌方信息，收集情报，从而为整个队伍提供全局性的战略与战术信息，是战场上唯一一个不对敌方造成直接伤害却能发挥作用的兵种。

“怎么获取信息”，我们人类用触觉，听觉，嗅觉来感知这个世界。同样地，雷达凭借其搭载的传感器——工业相机，激光雷达，无线电模块，配合工作，重现整个赛场，对敌方机器人进行实时的追踪检测，获取空气中电磁波中的信息。解析各种密码与信息。

“怎么提供信息”，通过裁判系统的链路，雷达能够将自身所获取到的信息经过自身处理后转发给其他兵种，从而提供给队伍敌方的位置，血量，状态等信息。

## 学习指南

### 编程语言：C/C++ 入门学习

面向对象编程是重要的编程思想，大家要理解并运用封装、继承和多态。此外，C++11 的一些新特性、标准库 STL 以及 C++ 多种设计模式能够给算法构建带来很大的便利。利用 C++11 的多线程机制进行并发编程的程序开发，熟练运用这些新特性也是视觉组的基本要求之一。

- [C/C++ 入门学习](https://www.bilibili.com/video/BV1et411b73Z/?Spm_id_from=333.337.searchcard.all.click&vd_source=3daba8d5d8cf289be4130d0b83d18873)

学到 P142 类和对象即可，学有余力的可以继续往下学完。

### Python 入门学习

Python 作为高级语言之一，带有的一些拓展库对于我们深度学习，目标检测，软件无线电开发等有很大的便利，可以参考一些 Python 的基础教程视频，类与对象，迭代器等基础知识要熟悉。

### OpenCV 入门学习

图像的基本操作（大家可根据目的重点学习下面内容）：

- 图像视频的读取与显示，摄像头调用
- 数据（图像、视频、xml、yaml）保存
- 图像颜色空间：多通道的分离与合并，颜色模型与转换
- 窗口交互操作：滑动条和鼠标响应
- 图像像素操作处理（二值化）
- 图像滤波、边缘检测
- 图像形态学操作
- 形状、轮廓检测
- 在图像上绘制几何图形，ROI 区域
- 单目相机标定和校正
- 图像分割（漫水填充法、分水岭法）

参考书籍：《学习 OpenCV3》《OpenCV4.0 快速入门》

### ROS2 基础

ROS2 全称机器人操作系统，是用于构建机器人应用的软件库和工具集。其中的节点编写，节点通信、话题发布与订阅、节点参数等概念非常重要，建议系统学习。

- [ROS2 中文文档](http://dev.ros2.fishros.com/doc/index.html)
- [鱼香 ROS2](http://dev.ros2.fishros.com)
- [鱼香 ROS2 视频教程](https://www.bilibili.com/video/BV1gr4y1Q7j5/)

除上述系统学习的相关算法知识，还有就是对 Linux 操作系统的学习和理解，理解“Linux 一切皆文件”的思想，熟悉相关 CLI 操作；学习 git 和 github 相关使用，如果感兴趣甚至可以开发一套自己的 vscode 开发环境。

### 深度学习入门

深度学习是利用多层神经网络自动提取数据特征，强调非线性和层次化的模式学习，可以对于深度学习有一个入门性的了解，例如神经网络原理，pytorch 机器学习库，Transformer 架构等。

### 软件无线电开发

软件无线电技术（Software Defined Radio, SDR）打破了传统硬件无线电的束缚，以其高度的灵活性和可扩展性，为无线通信技术的创新与发展开辟了广阔的空间。在新规则背景下，无线电成为雷达站的核心功能之一。对于无线电的学习，可以从 GNU Radio 开始，逐步了解信号解调，纠偏滤波等数学原理以及代码实现，实现简单的信号解析。
