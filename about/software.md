# 关于软件组

软件组的工作，就是编写上位机与客户端程序，搭建物理模拟器与数据可视化平台，甚至开发战队内部的高效协作工具。赛场上清晰流畅的图传画面、操作手眼前的战术 HUD、赛后全盘复盘的数据看板，以及辅助瞄准与智能决策系统，全部依靠软件组构建实现。小到一个快捷键的响应逻辑，大到整支战队的数字信息流与战术指挥系统，都由软件负责实现。

软件是机器人的“天眼与参谋”：如果说机械是躯体、电控是神经与动作执行者，软件则是赋予操作手洞察全局的“全息视界”与战队决策的“智慧大脑”。电控让机器人动起来，软件让机器人与团队协同配合得更聪明、更高效。

## 招新目标

- 对 RoboMaster 机甲大师赛事与上位机/系统开发充满热爱，愿意投入时间深耕技术，能接受程序架构反复重构、网络与性能反复调优的攻坚过程。

**零基础同学同样可以加入**

只要你有对代码的热爱与求知欲。

- 动手能力强，敢于敲代码、搭环境、搭框架，不畏惧各种报错与崩溃调试。
- 能够沟通协作，积极配合电控组、视觉算法组及操作手同学，有强烈的团队协作意识，杜绝脱离团队的单打独斗。
- 具备良好的自主学习能力，遇到 bug、底层协议困惑或环境配置难题时，愿意主动查阅官方文档、翻看开源社区，敢于多交流提问。

## 学习指南

### 学习内容

- **编程基础**：熟练掌握 C/C++ 或 Python，了解/接触 C#、Java 等其他工程语言。
- **上位机与交互**：Qt 等跨平台 GUI 开发框架，或现代前端框架（Vue / React），掌握多线程编程与 UI 渲染交互。
- **系统与工具**：Linux 操作系统日常配置与 Bash 命令行，Git 等版本管理工具与协作规范。
- **网络与通信**：TCP/UDP、WebSocket、MQTT 等网络通信协议，音视频实时推流（RTSP/WebRTC）与数据封包解析。
- **仿真与智能**：物理模拟器（Unity / UE / Gazebo / Isaac Sim），了解 OpenCV 视觉处理基础与常见数据可视化分析工具。
- **比赛与团队**：熟悉 RM 比赛规则与裁判系统通信协议，参与战队项目研发全流程。

### 推荐学习资源

- **菜鸟教程 / 廖雪峰的官方网站**：涵盖主流编程语言与 Git 基础，简单清晰，适合零基础同学快速上手。
- **VS Code / CLion / Qt Creator**：现代工程必备开发工具与集成开发环境（IDE）。
- **Linux 学习**：《鸟哥的 Linux 私房菜》或 B 站各类 Linux 基础命令行入门教程。
- **Qt 官方文档 & B 站精选教学**：学习桌面客户端交互、多线程及网络通信的经典入口。
- **LearnGitBranching**：可视化交互式 Git 分支学习网站，轻松玩转团队协同版本控制。
- **B 站相关开源仿真与上位机教程**：各大高校 RM 战队开源的客户端/上位机、Gazebo/Unity 仿真项目讲解。

同时还有海量优秀的开源社区（如 GitHub、Gitee）和技术博客，大家要多学会使用官方文档、搜索引擎及 AI 工具检索资料，主动探索适合自己的学习路径。
