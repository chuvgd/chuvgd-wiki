# C 语言第0课

我们决定从 C 语言开始，是因为他太过于基础，也最适合入门。（有人认为 python 更容易理解，但他对我们学习其他语言没什么好处）

从 C 语言开始，我们会从头开始 “编程思想”。我们从 C 这个最原始的语言理解 “人们一开始编程时是想在做什么”。

1. 变量、值和程序
2. 类型、复合数据类型
3. 运算、分支和循环
4. 程序和函数
5. 预处理：include、宏和条件编译
6. 声明、定义和引用，多文件编程
7. 编译器、makefile和cmake
