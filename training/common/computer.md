## 其他一些建议

1. 请注意管理你的C盘
   C盘在出厂设置时默认为系统盘，所以在安装软件时都会默认装在C盘，但是C盘本身会有所有数据的缓存以及系统个垃圾，当C盘太拥挤时电脑会很卡，如果等到那时再清理就会变得无比困难，最简单的方法已经是重装系统了
2. 请不要在软件安装目录中出现中文与奇怪字符
   在一部分的工程软件安装中，中文和奇怪字符(@#$)出现在路径会报出莫名其妙的错误，特别是当电脑的用户名为中文时
3. 尝试科学数据跨境
4. 请摆脱百度搜狗360等浏览器
   很多时候这些浏览器并不能给到最直接有用的结果，并且有广告，推荐Google或者Edge浏览器（比较搜索CubeMX下载和STEAM中文版时两个浏览器给出的结果，你会发现这些浏览器劣等结果的权重往往莫名其妙的高
5. 请务必从官网下载软件
   懂得辨别如真假steam这样的陷阱
6. 请设置一下打开文件后缀名
   如果你连什么是压缩文件都不知道：[打开文件后缀名教程请看这里](https://blog.csdn.net/wxy2020915/article/details/126527442 )
7. 关于压缩文件
   请自行搜索其定义
   常见的压缩文件后缀有如：zip，7z，rar等
   不要在压缩文件里面打开压缩文件
   推荐解压软件Bandizip， WinRAR
8. 常见快捷键：
   Ctrl + C：复制
   Ctrl + V：粘贴
   Ctrl + Z：撤回
   Ctrl + X：剪切
   Ctrl + A：全选
