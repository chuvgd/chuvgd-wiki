# 编程

机器人队的工作主要在嵌入式和Linux上，主要的编程语言包括 C、C++、Python，并且 Matlab 也是一个重要的工具。

以上语言是队伍内刚需的学习内容，不过有精力也可以去玩玩其他语言（编程本身也是很有意思的学问，但请记住他只是一个**工具**）（同时我们正在策划成立软件组，其中和 web 相关的开发也涉及一些网页前端语言和 nodejs 等东西）

不同的编程语言都在做同一间事情：数据和运算。但是他们有各自的优势和适用领域。
