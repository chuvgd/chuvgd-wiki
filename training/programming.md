# 编程

机器人队的工作主要在嵌入式和Linux上，主要的编程语言包括 C、C++、Python，并且 Matlab 也是一个重要的工具。

不同的编程语言都在做同一个程序，但是他们有各自的优势和适用领域。

- C 语言更贴近底层、入门较简单、运行速度快，适用于嵌入式、操作系统等地方
- C++ 是从c语言发展而来的，有更多方便的语法，可以面向对象编程，效率较高，常用于底层算法程序编写
- python 语法很简单，方便编写和使用，在RM比赛中雷达和算法常用。
