# 电控

学习内容：
1. C/C++
2. 嵌入式（主要为STM32）
3. 部分控制原理
4. 一点点机器人运动学/运动学知识
5. 一点点数学（例如一点复变和线代）
6. Git
7. 一点硬件知识（嘉立创画出最小系统板和小夜灯的程度）
