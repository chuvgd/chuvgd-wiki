## 配置：CubeMX 生成 Keil 工程

keil本身没有代码，也没有库，通过cubemx生成基于hal库的代码，开发会更快

这里我们先把芯片包下载好，可以使用FubeMX来提前下载好：[FubeMX](https://docs.baud-dance.com/docs/stm32/FAQ/fubemxInstallPackage/)

**基础四步配置**

0. 创建CubeMX项目
1. 配时钟
2. 配调试接口
3. 生成配置

**步骤如下**

0.   创建项目

     -    打开 STM32CubeMX，点击左上角的 File -> New Project...（新建工程）
         ![image-20261017193738416](/training/embedded/assets/image-20261017193738416.webp)
         
     -   在左上角的 Commercial Part Number 搜索框中输入芯片型号 stm32f103c8t6。在下方列表中选中对应的芯片（STM32F103C8T6)，然后点击右上角的 Start Project
     ![image-20261017194622677](/training/embedded/assets/image-20261017194622677.webp)

1.   配时钟（RCC）

     -   在 Pinout & Configuration 页面，展开左侧的 System Core，点击 RCC。在 High Speed Clock (HSE) 的下拉菜单中选择 Crystal/Ceramic Resonator（使用外部晶振）
         ![image-20261017194708715](/training/embedded/assets/image-20261017194708715.webp)

     -   切换到顶部的 Clock Configuration 标签页。将 PLL Source Mux 选择为 HSE，系统时钟源（System Clock Mux）选择为 PLLCLK。最后在 HCLK (MHz) 框中输入 72 并回车，软件会自动计算倍频和分频系数（72MHz 是该芯片的常用最高主频）
         ![image-20261017194833094](/training/embedded/assets/image-20261017194833094.webp)
         ![image-20261017194826911.webp](/training/embedded/assets/image-20261017194826911.webp)

2.   配调试接口（SYS）

     -   回到 Pinout & Configuration 页面，展开左侧的 System Core，点击 SYS。在 Debug 下拉菜单中选择 Serial Wire。这样会占用 PA13 和 PA14 引脚作为 SWD 调试接口，方便后续下载和仿真
         ![image-20261017195804019](/training/embedded/assets/image-20261017195804019.webp)

3.   生成配置

     -   切换到顶部的 Project Manager 标签页。填写 Project Name（工程名，如 my_first_project），选择 Project Location（保存路径）。最关键的是，将 Toolchain / IDE 选择为 MDK-ARM（即 Keil 环境）
         ![image-20261017195943598](/training/embedded/assets/image-20261017195943598.webp)

     -   点击右上角的 GENERATE CODE 按钮，等待代码生成。如果以后你修改了任何配置，都需要，重新生成一次
         ![image-20261017200015023](/training/embedded/assets/image-20261017200015023.webp)

     -   生成成功后，会弹出提示框。点击 Open Project 即可自动打开 Keil 软件并加载你的工程；也可以点击 Open Folder 查看生成的本地文件
         ![image-20261017200025569](/training/embedded/assets/image-20261017200025569.webp)

至此完成了 cubemx 基础必须的配置，我们生成了一个可用的 keil 工程。我们可以在上一步 Open Project 打开 keil 试试：

![image-20261017203650458.webp](/training/embedded/assets/image-20261017203650458.webp)

点击编译按钮 `0 error 0 warning` 编译成功。我们再看看这个 CubeMX生成项目的内容有什么：

![image-20261017203647818.webp](/training/embedded/assets/image-20261017203647818.webp)

- 我们在 Core 中找到了 `main.c`，他是包含 main 函数和其他外设初始化设置
- Core 中的其他文件就是我们通过配置 CubeMX 自动生成的配置文件，他被 `main.c` 调用
- MDK-ARM 和 CMSIS 中是启动文件和寄存器驱动，我们不用管
- `STM32F1xx_HAL_Driver` 就是HAL库本体，CubeMX 只是把他 copy 了过来

现在我们有一个空项目了，我们学习使用keil试试
