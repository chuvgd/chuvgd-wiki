## 0. 什么是编程，什么是 C 语言

编程的核心有两个：

- 数据
- 运算

通过一定规则的运算，把数据变为希望的样子，就是程序。

- 运算：把一段信息变为另一段信息。
- 数据：可以被编码保存的信息。
- C 语言：编程语言里的“老祖宗”，很多现代语言都受它影响。
- 语法：按照一定写法，编码一段程序。
- 语法糖：除了基本语法外，为了方便而创建的语法。

C 语言的特点：

- 接近底层，能直接操作内存和二进制位。
- 效率高，常用于操作系统、嵌入式、驱动、基础库。
- 语法相对简洁，但需要程序员自己管理很多细节。
- 很多现代语言：C++、Java、C#、Go、Rust 等都受到 C 的影响。

## 1. 变量和字面量

运行中的程序，会涉及这几种空间：

1. **硬盘**  
   保存程序文件，断电后还在，速度慢。

2. **内存中的代码段 / 只读数据段**  
   如 `.text`、`.rodata`。运行时操作系统会把程序代码和常量加载到内存，速度比硬盘快非常多。

3. **内存中的栈和堆**  
   - 栈：存函数调用信息、局部变量等。
   - 堆：存动态分配的数据，如 `malloc` 出来的内存。

4. **寄存器**  
   在 CPU 内部，速度极快，数量很少，运算时随用随放。

### 字面量（字面值）

字面量：直接写在代码里的值，如：

```c
1
3.14
'A'
"hello"
```

字面量通常不占栈空间，可能直接编码在指令里，或放在只读数据段。  
字符串字面量如 `"hello"` 通常放在只读数据段，试图修改它属于未定义行为。

### 变量

变量：有名字的存储位置，如：

```c
int a;
```

局部变量通常占栈空间。  
全局变量、静态变量通常放在数据段或 BSS 段。  
动态分配的数据放在堆上。

补充：

- **声明**：告诉编译器这个名字和类型，如 `extern int a;`
- **定义**：真正分配存储或给出函数体，如 `int a = 1;`
- **初始化**：定义时给初值。
- **赋值**：定义后改变值。

## 2. 基本数据类型和基本运算

### 基础数据类型

包括：

- 以整数形式储存：
  - `char`、`short`、`int`、`long`、`long long`
  - 修饰词：`signed`、`unsigned`
  - `_Bool` 表示布尔值，C99 后也可用 `<stdbool.h>` 里的 `bool`
- 以小数形式储存：
  - `float`、`double`、`long double`
- 指针：
  - 保存另一个变量或数据所在的内存地址。
- `void`：
  - 表示“无类型”或“无返回值”。

类型决定：

- 占多少字节
- 能表示什么值
- 能做哪些运算
- 对齐要求

注意：C 标准没有固定 `int` 一定是几字节。常见平台上 `int` 通常是 4 字节，但应以 `sizeof` 为准。

### 基本运算

赋值：

```c
a = 1;
```

数值运算：

```c
+ - * / %
```

注意：

- 整数除法会截断，如 `5 / 2 == 2`。
- `%` 是取余，只能用于整数。
- 除数为 0 是未定义行为。
- 有符号整数溢出是未定义行为。

关系运算：

```c
> < >= <= == !=
```

结果是真 / 假，C 中通常用 `1 / 0` 表示。

逻辑运算：

```c
&& || !
```

`&&` 和 `||` 有短路求值：

- `a && b`：如果 `a` 为假，不再计算 `b`。
- `a || b`：如果 `a` 为真，不再计算 `b`。

位运算：

```c
<< >> & | ^ ~
```

直接操作二进制位。注意有符号数的移位、溢出等细节可能依赖实现或属于未定义行为。

强制类型转换：

```c
(类型)表达式
```

例如：

```c
(int)3.14
```

其他复合运算和语法糖：

```c
+= -= *= /= %=
++ --
?:
```

注意：`?:` 是条件运算符，不严格属于“复合赋值语法糖”。

优先级和结合性容易出错，建议多用括号。

## 3. 程序流程：顺序、分支、循环

程序默认并不是“乱跳”的，而是按照一定流程执行。最基本的程序流程有三种：

- **顺序结构**：从上到下依次执行。
- **分支结构**：根据条件选择执行哪一段。
- **循环结构**：满足条件时重复执行某一段。

复杂程序，基本上都是这三种结构的组合。

### 3.1 顺序结构

顺序结构是最简单的流程：代码从上往下执行。

```c
int a = 1;
int b = 2;
int c = a + b;
```

执行顺序就是：

1. 给 `a` 赋值 1
2. 给 `b` 赋值 2
3. 计算 `a + b`，结果赋给 `c`

多条语句可以用一对大括号 `{ ... }` 组成复合语句，也叫块：

```c
{
    int a = 1;
    int b = 2;
    int c = a + b;
}
```

块也常常和分支、循环、函数一起使用。

---

### 3.2 分支结构

分支结构让程序根据条件选择不同路径。

#### if / else

```c
int score = 75;

if (score >= 60) {
    printf("及格\n");
} else {
    printf("不及格\n");
}
```

如果还有多种情况，可以用 `else if`：

```c
int score = 85;

if (score >= 90) {
    printf("优秀\n");
} else if (score >= 60) {
    printf("及格\n");
} else {
    printf("不及格\n");
}
```

C 语言里判断真假时：

- `0` 表示假
- 非 `0` 表示真

所以下面写法也合法，但不推荐：

```c
if (1) {
    // 永远执行
}

if (0) {
    // 永远不执行
}
```

#### 条件运算符 ?:

简单二选一时，可以用条件运算符：

```c
int a = 10;
int b = 20;
int max = (a > b) ? a : b;
```

意思是：如果 `a > b` 为真，取 `a`，否则取 `b`。

#### switch

当一个整数或枚举有多个固定分支时，可以用 `switch`：

```c
char op = '+';
int a = 3;
int b = 5;
int result = 0;

switch (op) {
    case '+':
        result = a + b;
        break;
    case '-':
        result = a - b;
        break;
    case '*':
        result = a * b;
        break;
    default:
        printf("未知运算符\n");
        break;
}
```

注意：

- `switch` 的条件通常是整数类型，如 `int`、`char`、`enum`。
- `case` 后面必须是整型常量表达式。
- 通常每个 `case` 后面要写 `break`，否则会“穿透”到下一个 `case`。
- `default` 处理没有匹配到的情况。

---

### 3.3 循环结构

循环用于重复执行一段代码。常见循环有 `while`、`do-while`、`for`。

#### while

```c
int i = 1;
int sum = 0;

while (i <= 10) {
    sum += i;
    i++;
}
```

执行逻辑：

1. 判断 `i <= 10`
2. 如果为真，执行循环体
3. 回到第 1 步继续判断
4. 如果为假，结束循环

#### do-while

`do-while` 至少执行一次循环体：

```c
int i = 1;
int sum = 0;

do {
    sum += i;
    i++;
} while (i <= 10);
```

注意末尾有分号。

#### for

`for` 最适合“次数明确”的循环：

```c
int sum = 0;

for (int i = 1; i <= 10; i++) {
    sum += i;
}
```

它把循环三要素写在一起：

```c
for (初始化; 循环条件; 每轮更新) {
    循环体;
}
```

等价于：

```c
初始化;
while (循环条件) {
    循环体;
    每轮更新;
}
```

#### break 和 continue

- `break`：立即跳出当前循环或 `switch`。
- `continue`：跳过本次循环剩下的部分，进入下一次循环。

```c
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break;  // 到 5 就结束整个循环
    }
    printf("%d ", i);
}
```

```c
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue;  // 偶数跳过
    }
    printf("%d ", i);
}
```

`break` 只跳出最内层循环或 `switch`，不会一次跳出所有嵌套循环。

#### goto

C 语言还有 `goto`，可以跳转到同一函数内的标签：

```c
goto end;

printf("不会执行\n");

end:
printf("结束\n");
```

但 `goto` 容易破坏程序结构，初学阶段了解即可，通常不推荐滥用。

---

### 3.4 控制流与函数

函数体内部也是由顺序、分支、循环组成的。`return` 会结束函数并返回结果。

例如，写一个函数计算 `1 + 2 + ... + n`：

```c
int SumToN(int n) {
    int sum = 0;

    for (int i = 1; i <= n; i++) {
        sum += i;
    }

    return sum;
}
```

再例如，判断一个数是不是素数：

```c
int IsPrime(int n) {
    if (n < 2) {
        return 0;
    }

    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            return 0;
        }
    }

    return 1;
}
```

这里同时用到了：

- 顺序结构：从上到下执行
- 分支结构：`if`
- 循环结构：`for`
- 函数返回：`return`

---

### 3.5 常见坑

- `if (a = b)` 是赋值，不是比较；比较应写 `a == b`。
- `if (...)`、`while (...)`、`for (...)` 后面误加分号，会导致循环体或分支体变成空语句。
- `switch` 忘记 `break`，会发生意外穿透。
- 循环变量忘记初始化或更新，可能死循环。
- `break` 只跳出最内层循环。
- `continue` 只用于循环，不用于 `switch`。
- 浮点数不要随便直接用 `==` 比较，循环条件里也要小心。
- `for (int i = 0; ...)` 中的 `i` 只在循环内可见，C99 及以后支持这种写法。
- 数组循环时注意边界，不要越界。

---

### 3.6 小结

程序流程的三大基础是：

- 顺序：从上到下执行。
- 分支：根据条件选择路径，如 `if`、`switch`。
- 循环：重复执行，如 `while`、`do-while`、`for`。

函数内部也是这些流程的组合。掌握顺序、分支、循环之后，再学习函数、多文件和复杂数据结构，会更容易理解。

## 4. 复合数据类型和复合运算（函数）

### 复合数据类型

#### 数组 array

一组同类型数据连续存放，用下标访问，下标从 0 开始。

```c
int a[5]; // a[0] ~ a[4]
```

注意：

- 数组越界不会自动检查，可能造成未定义行为。
- 数组名在多数表达式中会退化为首元素指针。
- 数组长度必须是编译期常量，变长数组 C99 支持但有限制。

#### 结构体 struct

把不同类型的数据组合成一个整体。

```c
struct Point {
    int x;
    int y;
};
```

使用：

```c
struct Point p;
p.x = 1;
p.y = 2;

struct Point *ptr = &p;
ptr->x = 3;
```

#### 枚举 enum

给一组整数常量起名字。

```c
enum Color {
    RED,
    GREEN,
    BLUE
};
```

默认从 0 开始递增：`RED == 0`，`GREEN == 1`，`BLUE == 2`。  
也可以手动指定：

```c
enum Color {
    RED = 1,
    GREEN = 5,
    BLUE
};
```

#### 联合体 union

多个成员共用同一块内存，同一时间通常只用一个成员。

```c
union U {
    int i;
    float f;
};
```

联合体的大小至少能容纳最大成员。写入一个成员后读取另一个成员，通常需要非常小心，很多情况属于实现定义或未定义行为。

---

### 复合运算：函数

函数的意义：

- 程序复用
- 简洁，提高可读性
- 逻辑清晰
- 便于调试、维护和分工

函数就是一个加工厂：输入数据，处理运算后输出数据。

一段最简单的运算也可以看成一个函数：

| 输入 | 输出 |
|---|---|
| 1, 2 | a + b |
| 结果 | 3 |

可以叫它 `Add` 函数，用 C 语言写就是：

```c
int Add(int a, int b) {
    return a + b;
}
```

相当于：

```text
f(a, b) = a + b
```

如果一段运算很长，反复写会让程序变得超级大：

```c
// 某一段程序
// 然后用了一段运算过程：
... 此处省略100行
// 后来又用了一遍：
... 此处省略100行
```

这时可以把这段运算包装成函数，每次使用时，把需要的变量送给函数，然后函数传出结果：

```c
int Add(int a, int b) {
    return a + b;
}

int main(void) {
    int x = Add(1, 2);    // 把 1, 2 送给 Add，得到 3
    int y = Add(10, 20);  // 把 10, 20 送给 Add，得到 30
    return 0;
}
```

### 为什么入口函数叫 main？

当你把整个程序看成一场巨大的复合运算，它其实就是一个函数。写在程序里时，就表现为一个核心函数，它就是整个程序。

老资历们制定了 C 标准，约定程序入口是 `main`。编译器、链接器和启动代码会配合调用 `main` 函数。

所以通常大家都用：

```c
int main(void) {
    return 0;
}
```

或者带参数：

```c
int main(int argc, char *argv[]) {
    return 0;
}
```

理论上可以通过链接器指定别的入口符号，但这通常会绕过 C 运行时初始化，属于非标准、不推荐的做法。

## 5. 作用域、生命周期和存储期

### 作用域

作用域：名字在代码中可见的范围。

常见作用域：

- 块作用域：`{ ... }` 内，如局部变量。
- 文件作用域：所有函数外，如全局变量。
- 函数作用域：一般只用于标签。
- 函数原型作用域：函数声明里的参数名。

### 生命周期 / 存储期

- **自动存储期**：局部变量，通常位于栈。进入块时创建，离开块后生命周期结束，不能再安全访问。
- **静态存储期**：全局变量、静态变量。程序加载时分配，程序结束时释放。
- **动态存储期**：由 `malloc`、`calloc`、`realloc` 分配，由 `free` 释放，位于堆。

原稿中“全局变量在程序最一开始运行后，就占用了堆栈空间”不准确。  
更准确的说法是：

> 全局变量和静态变量具有静态存储期，通常位于数据段或 BSS 段，不在栈上。程序加载时分配，程序结束时释放。

局部变量：

```c
void f(void) {
    int x = 1; // 自动存储期，通常在栈上
}
```

离开 `f` 后，`x` 的生命周期结束。

静态局部变量：

```c
void f(void) {
    static int count = 0;
    count++;
}
```

`count` 只初始化一次，函数调用结束后仍然存在。

## 6. 多文件、extern、include、定义 vs 声明 vs 使用

如果想把程序分为多个模块，往往会创建多个 `.c` 文件，用来储存不同的模块。

常见做法：

- `.c` 文件：放函数定义、变量定义。
- `.h` 文件：放函数声明、类型声明、宏、外部变量声明。

### 定义、声明、使用

- **声明**：告诉编译器“有这个名字，类型是什么”。  
  如：

  ```c
  int Add(int a, int b);
  extern int g_count;
  ```

- **定义**：真正分配存储或给出函数体。  
  如：

  ```c
  int g_count = 0;

  int Add(int a, int b) {
      return a + b;
  }
  ```

- **使用 / 调用**：在代码里访问或调用。  
  如：

  ```c
  int x = Add(1, 2);
  g_count++;
  ```

C 语言里说“引用”时，通常只是“使用某个名字”的意思，不是 C++ 里的引用类型。

### extern

`extern` 用于声明外部链接的变量或函数。

```c
extern int g_count;
```

表示 `g_count` 在别的文件中定义。

函数声明默认就是外部链接，所以：

```c
int Add(int a, int b);
```

等价于：

```c
extern int Add(int a, int b);
```

### include

`#include` 是预处理指令，会把另一个文件的内容插入到当前位置。

```c
#include <stdio.h>
#include "math.h"
```

- `<...>`：通常用于系统头文件。
- `"..."`：通常用于自己写的头文件。

头文件通常要防止重复包含：

```c
#ifndef MATH_H
#define MATH_H

int Add(int a, int b);
extern int g_count;

#endif
```

或者：

```c
#pragma once
```

### 多文件示例

`math.h`：

```c
#ifndef MATH_H
#define MATH_H

int Add(int a, int b);
extern int g_count;

#endif
```

`math.c`：

```c
#include "math.h"

int g_count = 0;

int Add(int a, int b) {
    g_count++;
    return a + b;
}
```

`main.c`：

```c
#include <stdio.h>
#include "math.h"

int main(void) {
    int x = Add(1, 2);
    printf("x = %d, g_count = %d\n", x, g_count);
    return 0;
}
```

编译：

```bash
gcc main.c math.c -o app
```

运行：

```bash
./app
```

注意：

- 头文件通常只放声明，不放变量定义和函数定义。
- 不要 `#include "xxx.c"`。
- 变量定义一般放 `.c`，其他文件用 `extern` 声明。
- 函数定义放 `.c`，头文件放函数声明。
- `static` 可以限制名字只在当前文件可见，或让局部变量具有静态存储期。
